# 排障手册

> 这篇按"症状 → 原因 → 动作"组织常见故障；给使用者与值班排查的人看。所有路径都在 `%USERPROFILE%\.codemaker-hub-light\` 下。

## 0. 先看这三处

| 位置 | 内容 |
|---|---|
| 设置 → 应用信息 | 版本、数据目录、数据库路径、Schema 版本、日志目录；「打开日志目录」直达 |
| `logs\hub-light.log.<日期>` | 主日志，按日滚动；启动阶段有 `phase` / `elapsed_ms` 行 |
| 设置 → 本地代理 | 代理是否运行、实际端口、Base URL、健康检查地址、请求/错误计数 |

> 反馈问题前请脱敏：不要粘贴 token、`auth.bin` 内容或完整回调链接；日志里的账号信息可以替换成 `<user>`。

## 1. 代理与客户端

### 1.1 客户端连不上，或端口不是 15721

- 默认端口 15721；被占用时自动回退 `15722–15800`，仍失败交给系统分配。
- **一律以「设置 → 本地代理」显示的端口为准**，把客户端的 Base URL 改成实际端口。
- 端口回退时界面会提示；改完端口需要先「保存设置」再「重启代理」。

### 1.2 改了端口或网关不生效

端口与网关只在代理重启时生效：先保存，再点「重启代理」。记录正文开关与积分换算系数是即时生效的，不需要重启。

### 1.3 启动后就能用吗

不能。默认网关是占位地址 `https://api.example.com`，**首次使用必须在「设置 → 代理与记录」填写可访问的兼容网关**，否则所有请求都会连接失败。

### 1.4 `/v1/models` 返回 503

模型目录还没缓存：登录后 `/validate` 成功才会写入。先完成登录，再重试。

### 1.5 转发接口返回 401

未登录、凭据已失效或已退出登录。若凭据过期（多端登录顶号、服务端提前轮换），后台会先用 `auth_key` 自动续期一次再判失效；仍 401 时到 **设置 → 账户** 点「重新检测 / 续期」，失败再重新登录即可。**代理不需要重启**。

若在登录页用「账号 + AuthKey」直登失败：

- 「账号名或 AuthKey 不正确。」→ 核对账号名与 AuthKey（区分大小写/空格）；必要时找管理员重置。
- 「登录请求被服务端拒绝（HTTP 4xx）。」→ 兼容网关可能未实现 `POST /api/v2/tokens`（通常 404）或参数被拒；先升级兼容网关。
- 网络错误 → 检查网关地址/TLS 与代理设置；失败不会清除已有登录态。

### 1.6 返回 403 `origin_not_allowed`

请求带了 `Origin` 头（典型是浏览器页面直接 fetch）。代理只接受本机 CLI/SDK 调用，这是设计如此；换成命令行或服务端 SDK。

### 1.7 返回 404

路径不在支持列表内。支持路径见 [docs/proxy.md](proxy.md) 的路由表；`/v1` 前缀可省略。

### 1.8 退出应用后客户端报错

代理随应用运行。关闭窗口只是隐藏到托盘，程序仍在；只有托盘「退出」或结束进程才会停掉代理。

## 2. 登录

### 2.1 浏览器登录后没有跳回应用

1. 确认点登录时浏览器确实打开了登录页（不是旧标签页）。
2. 若浏览器没有自动拉起应用：回到登录页，展开「浏览器没有自动跳回应用？手动粘贴回调链接」，粘贴地址栏里以 `codemakerhub-light://auth/callback` 开头的完整链接，提交。
3. 链接必须属于**当前这次**登录会话：过期、已用过或上一次登录的链接会被拒绝（这是有意为之，防止回调链接重放）。

### 2.2 点回调链接提示"没有打开此链接的应用"

深链 scheme 由应用**在启动时**写入注册表（`HKCU\Software\Classes\codemakerhub-light`），所以安装后必须先运行一次应用。自查：

```powershell
reg query HKCU\Software\Classes\codemakerhub-light /s
```

应能看到 `URL Protocol` 与 `shell\open\command` 指向当前 exe。指向旧路径（移动过 exe）时，再启动一次应用就会被改写；键不存在说明启动时注册失败，看 `logs\hub-light.log` 里的「注册深链 scheme 失败」，此时仍可用手动粘贴登录。

### 2.3 登录卡在"等待浏览器完成登录"

- 登录总超时 300 秒，轮询间隔 2 秒；连续 3 次网络错误会直接转失败。
- 超时后先重试；若网络策略拦截了回调，可换网络再试。
- 仍未完成就用手动粘贴链接兜底。

### 2.4 账号页面的字段含义

「账号」是登录账号，「部门」等字段来自上游网关 `/validate` 的返回；网关不返回时对应行为空。工号类字段没有服务端来源，界面不展示。

## 3. 用量与额度

### 3.1 额度卡显示 403 / 404 / 「旧数据」

上游网关拒绝、额度接口不存在或网络不可达。应用会保留上次成功数据并标注「旧数据」；稍后点「刷新额度」重试，必要时看日志。

### 3.2 请求页是空的

只有**经过本机代理**的请求才会入库。检查客户端 Base URL 是否指向本机代理、代理是否在运行。若「今天」为空但概览有数据，先切「全部」确认是否只是时间范围问题（时间范围按本机本地日计算）。

### 3.3 本月数字和本机统计对不上

两者口径不同，不是同一份数据：

- **账号级**（月度额度、本月 token/消耗、模型分布、24 小时曲线）：来自上游网关，包含你在其他设备/客户端上的用量。
- **本机级**（今日 token/费用、30 天费用、请求明细）：只统计经过本机代理的请求。

### 3.4 导出的 CSV 打不开或数字不对

- 导出按**时间范围**取数，不应用协议/状态/模型筛选；「全部」导最近 30 天，单次上限 20 万行（超出会截断并在提示里说明）。
- 编码是 UTF-8 BOM，Excel 可直接打开；费用固定 4 位小数。
- 以 `=` `+` `-` `@` 开头的文本会被前置单引号，避免 Excel 当公式执行。

### 3.5 清掉的请求还能在导出的 CSV 里看到

「用量保留天数」只清理本地数据库里的明细、会话、日聚合与超量额度快照；`exports\` 下已经导出的 CSV 不会被删。

## 4. 启动与崩溃

### 4.1 应用无声退出（托盘图标突然消失，主日志没有报错）

先看 `logs\panic.log`：存在的话里面是 panic 的 `文件:行:列`、消息与回溯（release 无控制台，默认 panic 不写主日志）。同时在事件查看器 → Windows 日志 → 应用程序里搜 `codemaker-hub-light` 的 `Application Error 1000`；`0xc0000409` 表示 Rust `panic = "abort"` 生效。

### 4.2 双击后窗口不出现，或提示「启动失败」

启动期的致命错误（数据目录、SQLite 打开、数据库迁移、托盘初始化）会弹窗提示，并把现场写入 `logs\startup-error.log`。按弹窗里的路径取该文件。

若 `settings.json` 损坏或校验不通过（例如手改成 `credit_to_yuan: 0`、把网关改成非回环的 `http://`），应用会把它重命名为 `settings.json.bad-<时间戳>` 并回退默认值，不会卡在启动阶段——但这意味着你之前的设置需要重新填。

### 4.3 界面一直停在「正在连接 CodeMaker Hub Light…」，或整窗白屏

「正在连接」最多持续 10 秒，超时会变成「无法连接本地后端」，并给出「重试连接」与「打开日志目录」两个入口。整窗白屏会被错误边界接住：页面级显示错误原因与「重试 / 打开日志目录」，根级异常显示「重新加载应用」。先看 `logs\hub-light.log` 与 `logs\startup-error.log`。

### 4.4 运行中日志文件在资源管理器里显示 0 字节

Windows 的目录元数据延迟，内容其实已写入；退出应用后再看就会显示真实大小。要立刻看到最新日志，先退出应用。

## 5. 构建相关

### 5.1 自己构建后启动，显示「无法访问此页面 / localhost 拒绝连接」

构建时漏了 `custom-protocol` feature（常见于直接用 `cargo build --release`）。改用 `pnpm tauri build --no-bundle` 或 `pnpm tauri build`。详见 [docs/development.md](development.md)。

### 5.2 `LNK4217: locally defined symbol memmove imported in function groupConcatInverse`

可以忽略，是 bundled SQLite 与旧 CRT 垫片相遇时的警告，不影响链接结果，只在 release 链接阶段出现。
